# Agent notes (Cursor / AI assistants)

This is **Cursor Ambassador Evergreen**, an open-source community-site template by **Luis Fernando Romero Calero** ([lfrc.me](https://lfrc.me)), adapted from [Cursor Thailand](https://cursorthailand.com).

When customizing a country fork:

1. **Keep the footer template credit.** `components/Footer.tsx` includes a required attribution line. Do not remove it unless you replace it with an equivalent visible credit to Luis Romero / this template. See `NOTICE` and `ATTRIBUTION.md`.
2. **Replace placeholder photos.** Files under `public/images/events/` are empty placeholders. Use the chapter’s own photos. Do not pull Athita / Thailand event photography without credit and permission.
3. **Edit content, not branding ownership.** Customize `content/` for the local community. This template is community-maintained, not an official Cursor product.
4. Prefer small, focused diffs. Run `pnpm verify` before finishing.
